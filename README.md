# OSTA_walkthroughs

Implementation of selected sections of [Orchestrating Spatial Transcriptomics Analyses with Bioconductor](https://bioconductor.org/books/release/OSTA/).

R and Python packages used were date-locked to 2026-07-04 (or for pypi, 2026-07-05) referencing [Posit Public Package Manager for CRAN](https://packagemanager.posit.co/client/#/repos/cran/setup/) for use in Positron across user projects, and [Posit Public Package Manager for pypi](https://packagemanager.posit.co/client/#/repos/pypi/setup) to lock user-scoped pip and uv installations.
 
For at least [background_section8.qmd](./background_section8.qmd), the configuration of a Python virtual environment for `reticulate` used pinned packages compatible with the 2026-07-04 date lock above.
